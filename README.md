# Integrade_Kota_Nuevo
**Integrade Kota Nuevo** adalah game *casual-simulation arcade* 2D bertema keberlanjutan kota (*Sustainable Cities and Communities*). Dalam game ini, pemain berperan sebagai seorang **BuzzNova** (kondektur/pramujasa halte bus kota) yang bertugas mengelola rute penumpang.  Dapat dimainkan melalui platform PC maupun langsung di browser (Web/WebGL).
